ReMatch PWA package

To install on iPhone/Android, upload the contents of this folder to an HTTPS web host (GitHub Pages, Netlify, etc). Open the resulting HTTPS URL on your phone. iPhone: Safari > Share > Add to Home Screen. Android: Chrome menu > Install app/Add to Home Screen. Works offline after first load (service worker cache). For local file opening, installability/offline service worker may not work; use a web host.
